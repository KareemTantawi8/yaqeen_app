# Yaqeen 1.1.0 — Release notes (copy into stores)

Use the **English** block for App Store “What’s New” (if you add English localization) and the **Arabic** block as the primary listing text. Google Play: paste Arabic into **Production → Release notes** (default language).

---

## English (≤ 4,000 characters)

```
What's new in Yaqeen 1.1:

• More reliable prayer notifications — schedules the next 7 days and refreshes after app updates or device restart
• Adhan settings — choose muezzin voice (Makkah, Madinah, Mishary, and more), enable/disable per prayer, and test playback
• Improved home prayer times — clearer layout and loading states
• Push notifications (Firebase) for prayer-related alerts when enabled
• Stability and performance improvements for Quran audio and Adhan playback
• Bug fixes for prayer time calculation and notification delivery on Android and iOS

Thank you for using Yaqeen. Send feedback to support@yaqeen.app
```
