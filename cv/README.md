# Kareem Mahmoud — CV

Professional, ATS-friendly resume for Senior Flutter / Mobile Developer roles.

## Files

| File | Use case |
|------|----------|
| `Kareem_Mahmoud_Senior_Flutter_Developer_CV.html` | Open in a browser — **all links are clickable** (email, phone, LinkedIn, GitHub, App Store). Print to PDF (Chrome: File → Print → Save as PDF) to keep hyperlinks. |
| `Kareem_Mahmoud_Senior_Flutter_Developer_CV_ATS.txt` | Upload to job portals and ATS systems that prefer plain text. Full URLs included for parsers. |

## Quick start

```bash
open cv/Kareem_Mahmoud_Senior_Flutter_Developer_CV.html
```

## Structure (v2)

1. Professional Summary  
2. Professional Experience (company → role → location tags → product box with store links → bullets)  
3. Published Applications (table: App | Context | Stack | Links)  
4. Additional Projects  
5. Technical Skills (two-column grid)  
6. Education  

**WAIE / Aldrees store links** are in the Al-Drees role and Published Applications table.

## Tips

- **Job applications:** Prefer the `.txt` file for ATS forms; export PDF from HTML for recruiters (links stay clickable in Chrome PDF).
- **GitHub:** Update Additional Projects links when repo URLs are public.
- **Tailoring:** Match summary and top bullets to each job posting (Flutter, Dart, Swift, payments, etc.).
